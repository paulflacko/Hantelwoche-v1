# Hantelwoche

Persönliche Trainings-App zum Fitnessplan (Kraft, Mobility, Yoga, Meditation, Atemübungen, Ernährung, Supplements).
Läuft als installierbare Web-App über GitHub Pages, auch offline.

Am Handy: Adresse öffnen, dann „Zum Home-Bildschirm“ (iPhone, Teilen-Symbol) bzw. „Zum Startbildschirm hinzufügen“ (Android, Menü ⋮).

Die Einträge bleiben nur auf dem Gerät. Übertragen geht über Einstellungen › „Daten als Datei sichern“ und „Sicherung laden“.
