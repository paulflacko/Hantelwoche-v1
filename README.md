# Hantelwoche

Persönliche Trainings-App zum Fitnessplan (Kraft, Mobility, Yoga, Meditation, Atemübungen, Ernährung, Supplements).
Läuft als installierbare Web-App über GitHub Pages, auch offline.

Am Handy: Adresse öffnen, dann „Zum Home-Bildschirm“ (iPhone, Teilen-Symbol) bzw. „Zum Startbildschirm hinzufügen“ (Android, Menü ⋮).

Die Einträge bleiben nur auf dem Gerät. Übertragen geht über Einstellungen › „Daten als Datei sichern“ und „Sicherung laden“.

## Inhalte und Quellen
- Übungsbibliothek mit rund 290 Übungen, davon über 220 mit Bild. Fotos aus der gemeinfreien [free-exercise-db](https://github.com/yuhonas/free-exercise-db), Yoga und Mobility als eigene Animationen.
- „Kopf und Gefühle“: 25 Selbsthilfe-Übungen aus Verhaltenstherapie, ACT, DBT und Achtsamkeit. Selbsthilfe, kein Ersatz für Therapie.
- Herkunft und Lizenzen aller Bilder und Inhalte: [docs/quellen-und-lizenzen.md](docs/quellen-und-lizenzen.md). Werkzeuge zum Neubauen der Bilder: [tools/](tools/README.md).
